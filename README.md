## Updating the archive

Before each deadline, record the actual 15 players, selling values, bank, free transfers, confirmed injuries, starting XI, captain, vice-captain, bench order and chip status. After the round, record actual results separately from projections. Explain changes to an agreed plan instead of silently replacing it.

No live FPL connection, automatic chat export or GitHub synchronization is configured by this repository.
